# Scale Map — visual skeleton

A static mockup of the Scale Map prospect page. **Look and feel only** — no logic,
no API calls, no generation. One placeholder example throughout.

This is a thing to react to, not a thing to ship.

Live: https://lloyd-yip.github.io/scalemap-skeleton/

Three files, no build step, no dependencies: `index.html`, `skeleton.css`,
`skeleton.js`.
